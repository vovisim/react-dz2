# Заметки

Приложение на React + Vite.

Запуск:

```
npm install
npm run dev
```

## Как это работает

**Добавление.** Текст заметки и категория хранятся в состоянии (`useState`). При отправке формы создаётся объект заметки с `id`, текстом, категорией и датой, и он добавляется в начало массива `notes` через `setNotes([note, ...notes])`. Пустые заметки не добавляются, поле ввода после добавления очищается.

**Удаление.** У каждой карточки есть кнопка ✕. Она вызывает `deleteNote(id)`, которая оставляет в массиве все заметки, кроме удаляемой (`notes.filter(...)`). Кнопка «Очистить все заметки» после подтверждения записывает в состояние пустой массив.

**Сохранение.** При запуске заметки читаются из `localStorage`. `useEffect` следит за массивом `notes` и при каждом изменении сохраняет его в `localStorage` через `JSON.stringify`, поэтому заметки остаются после перезагрузки страницы.

**Поиск и счётчики.** Строка поиска фильтрует заметки по тексту и категории. «Всего заметок» — длина всего массива, «Найдено» — длина отфильтрованного.
